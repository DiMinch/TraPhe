# TraPhe - Hệ thống quản lý chuỗi cửa hàng cà phê

TraPhe là hệ thống quản lý chuỗi cửa hàng cà phê & trà được thiết kế theo mô hình vận hành hiện đại, số hóa toàn bộ quy trình từ bán hàng online, vận hành tại quầy đến quản trị nội bộ chuỗi.

## 🚀 Tech Stack

- **Frontend:** React 19, Vite, TypeScript, Tailwind CSS, shadcn/ui
- **Backend:** Spring Boot 4.0.4 (Java 21), PostgreSQL (Supabase)
- **Deployment:** Vercel (FE), Railway (BE)

## 📁 Cấu trúc thư mục

- `/frontend`: Chứa mã nguồn React SPA.
- `/backend`: Chứa mã nguồn Spring Boot RESTful API.

## 👨‍💻 Phân công

- **FE Developer:** Customer Web, POS interface, Admin dashboard
- **BE Developer 1:** Auth, Order flow, Inventory/Recipe, POS backend, Loyalty engine
- **BE Developer 2:** Menu/Branch management, Promotions, Reports, System config, Deploy
